# Student Management System

A simple command-line student management application written in Python.

## Features

- Add new students with name, age, and grade information
- List all students
- Search for a student by name
- Update a student's grade
- Remove a student

## Requirements

- Python 3.8+

## Usage

```bash
python student.py
```

## Running Tests

```bash
python -m pytest test_student.py -v
```
